## 📌 Overview

This folder contains the **results, outputs, and deliverables** from Week 4 of the DACA programme. Week 4 focused on **SQL aggregation** – transforming raw transaction data into business intelligence through `GROUP BY`, `HAVING`, CTEs, and window functions.

The outputs are organised into four subfolders:

| Subfolder | Contents |
| :--- | :--- |
| **Week_4_Conclusions/** | Summary of the week's outcomes and key recommendations |
| **Week_4_Pictures/** | Screenshots (empty – no screenshots were taken this week) |
| **Week_4_Presentation/** | Group presentation materials |
| **Week_4_Tables/** | Query results and aggregated data |
