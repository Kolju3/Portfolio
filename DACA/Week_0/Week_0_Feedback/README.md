## 📌 Overview

This document captures my personal reflections on Week 0 of the DACA programme. It describes my experience with the onboarding process, the challenges I faced, and the lessons I learned.

---

## 🧠 Overall Experience

The tasks in Week 0 were **not technically difficult**. Each individual step – creating a GitHub account, setting up Supabase, installing VS Code – is straightforward on its own.

**However**, the challenge was not in the difficulty of each task, but in **understanding the bigger picture**. I often found myself confused about why we were doing certain things and how all the pieces fit together.

> *"I didn't fully understand what was happening or why we were doing each step. This made the process feel overwhelming at times."*

---

## 🔥 Biggest Challenges

### 1. GitHub Confusion

I had some previous experience with GitHub from about **4 years ago**, but that experience was frustrating. I ran into version management problems and eventually abandoned using Git altogether.

This time, I approached it differently:
- Followed the onboarding materials carefully
- Asked questions when stuck
- Used the 5-step protocol when encountering errors

**Result:** I successfully got my GitHub repository working and made my first commits without the version management problems I had experienced before.

### 2. VS Code & Connection Issues

Getting VS Code configured correctly and establishing connections between tools was the most challenging part of the week:

- **SQLTools connection to Supabase** – I encountered the `self signed certificate in certificate chain` error. This was confusing because I wasn't sure if the problem was my credentials or something else.
- **Understanding the connection string format** – differentiating between Session pooler and Direct connection required careful reading.
- **VS Code workspace settings** – I initially had issues saving the connection due to workspace settings conflicts.

**Resolution:** By following the troubleshooting steps in the guides and using AI assistance, I was able to resolve these issues.

## 💡 Key Lessons Learned

1. **Read the error messages** – they often contain the solution
2. **Follow the 5-step protocol** – don't stay stuck for more than 15 minutes without asking for help
3. **Don't rush** – understanding why you're doing something is more important than just doing it
4. **Previous negative experiences are not permanent** – I got GitHub working this time despite past frustrations
5. **AI tools are helpful**, but you still need to understand the fundamentals

---

## 📝 Future Improvements

- Start reviewing the weekly materials earlier
- Set up the development environment more systematically
- Document connection settings immediately (not after troubleshooting)
