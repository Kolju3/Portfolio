## 🔧 How to Use These Files

### For NotebookLM

1. Go to [NotebookLM](https://notebooklm.google.com/)
2. Create a new notebook (e.g., "DACA Week 0")
3. Upload all files from this folder
4. Ask questions like:
   - *"What is the DACA programme structure?"*
   - *"Who are the key people at UrbanStyle?"*
   - *"What data problems does UrbanStyle face?"*
5. Generate an Audio Overview for each new set of materials

### For Independent Reading

Simply open the `.md` files in any text editor or Markdown viewer. They are written in a conversational tone suitable for both human reading and AI ingestion.

## 📚 Why These Files Exist

These RAG documents are part of DACA's **incremental RAG approach**:

- **CORE files** (4) remain permanently in the notebook – they contain foundational information about UrbanStyle and DACA
- **Weekly files** (2 per week) are added each week – they contain specific concepts and applications for that week
- **Files accumulate** – by Week 10, the notebook contains 26 files, making the AI increasingly knowledgeable

This approach means your AI learning companion **grows with you**, always knowing everything you've learned so far.
