## 📌 Week Overview

**Week 0** is the onboarding week of the DACA (Data Analytics Career Accelerator) programme. The goal of this week is to set up all the necessary tools and environments that will be used throughout the remaining 10 weeks.

Unlike the following weeks, **Week 0 involves no coding or data analysis**. Instead, it focuses on:

- Understanding the DACA programme structure and philosophy
- Setting up a professional development environment
- Creating the foundational infrastructure for the entire portfolio
