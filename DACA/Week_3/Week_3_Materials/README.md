## 📌 Overview

This folder contains all the **course materials** provided during Week 3 of the DACA programme. The focus of this week is **SQL JOINs** – learning how to combine data across multiple tables to answer business questions that require information from sales, customers, products, and inventory.

The materials are divided into two main subfolders:
- **Main materials** – The workbook and group work guide
- **`Week_3_RAG/`** – RAG-optimised background documents for NotebookLM
