## 📌 Overview

This folder contains the **results, outputs, and deliverables** from Week 3 of the DACA programme. Week 3 focused on **SQL JOINs and business intelligence** – combining UrbanStyle's fragmented data tables to answer real business questions.

The outputs are organised into four subfolders:

| Subfolder | Contents |
| :--- | :--- |
| **Week_3_Conclusions/** | Summary of the week's outcomes and key recommendations |
| **Week_3_Pictures/** | Screenshots (empty – no screenshots were taken this week) |
| **Week_3_Presentation/** | Group presentation materials |
| **Week_3_Tables/** | CSV exports of query results |
