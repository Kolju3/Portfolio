## 📄 Notebook Structure

The notebook follows a clear pipeline:

```text
Supabase (or CSV fallback)
  ↓
sales: 10,118 rows + customers: 3,150 rows
  ↓
LEFT merge on customer_id → 10,118 × 20
  ↓
Data cleaning → 8,950 rows
  ↓
2,540 unique customers
  ↓
Recency + Frequency + Monetary calculation
  ↓
RFM scores (1–5) → customer segments
  ↓
Plotly visualisations + rfm_segments.csv export
```
