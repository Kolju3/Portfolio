## 📌 Overview

This folder contains all the **course materials** provided during Week 5 of the DACA programme. The focus of this week is **Data Visualisation & Dashboard Design** – learning how to select appropriate chart types, design effective dashboards, and create interactive visualisations.

The materials are divided into two main subfolders:
- **Main materials** – The workbook, setup guides, and reference documents
- **`Week_5_RAG/`** – RAG-optimised background documents for NotebookLM
