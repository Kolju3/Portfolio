### 5_0_R1_viz_design_concepts-rag.md – Visualisation Fundamentals

This document covers the **core visualisation concepts** needed for Week 5 of the DACA programme.

#### Key Topics Covered

| Topic | Description |
| :--- | :--- |
| **Why Visualisation Matters** | Human brain processes visual information 60,000x faster than text |
| **Chart Types** | Line, bar, pie, scatter, heatmap, KPI cards – when to use each |
| **Dashboard Anatomy** | Pealkiri, KPI cards, peadiagramm, tugigraafikud, filtrid |
| **One-Screen Rule** | No scrolling – every element must earn its place |
| **Data-Ink Ratio** | Tufte's principle – every pixel must carry information |
| **Colour Theory** | Categorical, sequential, meaningful colours; colourblind accessibility |
| **F-Muster & Z-Muster** | How the eye scans a dashboard |
| **Knaflic's Principles** | Affordances, accessibility, aesthetics |
| **Dual-Track** | Power BI (Track A) vs Plotly + Streamlit (Track B) |

#### Example Concepts

**Chart Selection Rule:**

| Business Question | Chart Type |
| :--- | :--- |
| "Are we growing?" | Line chart |
| "What's our best product?" | Bar chart |
| "How is revenue distributed?" | Pie chart (max 5 segments) |
| "Is there a relationship?" | Scatter plot |
| "What's the most important number?" | KPI card |

**Data-Ink Ratio:**

> *"Maximise the data-ink ratio. Every pixel on the screen must carry information. Everything else is noise."* – Edward Tufte

**Colour Rules:**
- Max 5-7 colours
- Green = growth, red = decline
- Never rely on colour alone (add arrows, text, patterns)
