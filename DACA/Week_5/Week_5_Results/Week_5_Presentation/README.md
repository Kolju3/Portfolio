## 🎯 Presentation Objective

The goal of this presentation was to:

1. **Present stakeholder dashboards** for CEO, Marketing, Operations, and Investors
2. **Demonstrate visualisation design principles** – chart types, layout, interactivity
3. **Provide key business insights** from each dashboard
4. **Show technical achievement** – overcoming data challenges (pagination, schema adaptation)

## 🔍 Key Findings Presented

### Roll A – CEO Dashboard (Kristi)

| Metric | Value |
| :--- | :--- |
| **Total Revenue** | €2,611,298 |

## 📊 Presentation Structure

The presentation followed this structure:

1. **Introduction** – Team introduction and project objective
2. **Methodology** – Visualisation design principles (Knaflic, Tufte)
3. **Roll A – CEO Dashboard** – Kristi's view (growth, revenue trends)
4. **Roll B – Marketing Dashboard** – Anna's view (products, cities, channels)
5. **Roll C – Operations Dashboard** – Liis's view (inventory, overstock)
6. **Roll D – Investor Dashboard** – Consolidated KPIs
7. **Key Insights** – Across all stakeholders
8. **Technical Achievements** – Pagination, schema adaptation, cross-platform
9. **Recommendations** – Actionable next steps
10. **Q&A** – Questions from the audience and mentor

---

## 💡 Key Takeaways

1. **Multiple stakeholders need different views** – one dashboard doesn't fit all
2. **Python/Plotly is viable for Linux users** – Track B is a powerful alternative to Power BI
3. **Supabase pagination is essential** – the 1,000-row limit requires explicit handling
4. **Inventory is a major risk** – €44M stock value against €2.9M annual revenue
5. **Online is a strategic channel** – 34.5% of revenue with higher AOV
