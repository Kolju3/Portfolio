## 📌 Overview

This folder contains the **results, outputs, and deliverables** from Week 8 of the DACA programme. Unlike previous weeks (which focused on SQL), Week 8 involved **Python analysis and dashboard creation**.

The outputs are organised into four subfolders:

| Subfolder | Contents |
| :--- | :--- |
| **Week_8_Conclusions/** | Summary of the week's outcomes and key findings |
| **Week_8_Pictures/** | Screenshots of code, analysis, and dashboard |
| **Week_8_Presentation/** | Group presentation materials (PDF) |
| **Week_8_Tables/** | CSV exports of analysis results |
