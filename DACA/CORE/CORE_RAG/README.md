## 🎯 Purpose

This folder contains **RAG (Retrieval‑Augmented Generation)** documents that provide rich background information about the fictional company **UrbanStyle.ltd** and the **DACA programme framework**.

These files are designed to be uploaded into **NotebookLM** (or any RAG‑enabled AI tool) so that the AI can answer questions about the project context, characters, and course logic with high accuracy and source attribution.

---

## 📄 Files Included

| File | Description |
| :--- | :--- |
| `CORE_R1_urbanstyle_company-rag.md` | Complete profile of UrbanStyle.ltd – its history, business model, data challenges, and KPIs. |
| `CORE_R2_urbanstyle_characters-rag.md` | Detailed personas of key stakeholders (Kristi, Toomas, Anna, Marko, Liis) with their communication styles and priorities. |
| `CORE_R3_daca_program_framework-rag.md` | The structure of the DACA programme – four‑component architecture, assessment, weekly rhythm, and pedagogical methods. |
| `CORE_R4_da_tools_guide-rag.md` | Comprehensive guide to the tools used in the course (PostgreSQL, Python, pandas, Power BI, Plotly, Streamlit, etc.) with practical advice. |

Additionally, weekly RAG files (like `Week_1_RAG/` inside each `Week_X_Materials` folder) will accumulate over the course, but these **four core files** remain constant and are the foundation for all AI queries.

---

## 🧠 How to Use with NotebookLM

1. Go to [NotebookLM](https://notebooklm.google.com/).
2. Create a new notebook (e.g., "DACA Programme").
3. Upload all four `CORE_R*.md` files.
4. You can now ask questions like:
   - *"What are UrbanStyle's main business challenges?"*
   - *"How does the DACA assessment system work?"*
   - *"Tell me about Toomas Kask's communication style."*
5. Generate an **Audio Overview** to listen to the content on the go.

---

## 🔍 Why This Approach?

- **Context‑aware** – the AI answers **only** based on these uploaded documents, reducing hallucinations.
- **Incremental learning** – as you add more weekly RAG files, the notebook grows with you.
- **Source transparency** – every answer includes a citation to the original document.

---

## 📝 Notes

- These files are **permanent** – they are never removed, even as weekly RAG files are added.
- They are written in a conversational tone, making them suitable for both human reading and AI ingestion.
