# 📖 INTRODUCTION – Programme Specifics

---

## 🎯 Purpose

The **INTRODUCTION** folder holds documentation that explains the **specifics of the DACA programme** – the tools we use, the vocabulary you’ll encounter, and how the course is structured.

These documents are meant to be read **before** diving into the weekly assignments, giving you a solid foundation of the programme’s philosophy and practical details.

## 🧠 Why These Documents Matter

- **Consistency** – everyone uses the same terminology and toolset.
- **Self‑service** – you can refer back to these documents whenever you forget a concept.
- **AI‑friendly** – the AI tools (NotebookLM, ChatGPT) are pre‑configured to work with the same language and logic described here.

---

## 🔍 Quick Reference

### Programme Structure
- **Duration:** 11 weeks (incl. Week 0)
- **Core components:** Mentor sessions, portfolio projects, e‑textbook, optional e‑learning catalogue.
- **Assessment:** Pass/Fail based on portfolio projects only.

### Key Tools
- **Database:** PostgreSQL (Supabase)
- **Querying:** SQL
- **Analytics:** Python (pandas, NumPy)
- **Visualisation:** Power BI (Windows) or Plotly + Streamlit (cross‑platform)
- **Version Control:** Git & GitHub

### Vocabulary
- **RAG** – Retrieval‑Augmented Generation (AI that references your uploaded documents)
- **4C** – Connection, Concepts, Concrete Practice, Conclusions (Sharon Bowman’s learning model)
- **Shu‑Ha‑Ri** – a progression model (follow → break → transcend)

## 📝 How to Use

1. **First week:** Read the *Programme Overview* and *Tech Stack Guide*.
2. **Before each session:** Review the *Glossary* for any unfamiliar terms.
3. **When using AI:** Follow the *AI Study Guide* for ethical and effective prompting.
4. **Refer back** any time you need clarity on the course expectations or tool setup.
