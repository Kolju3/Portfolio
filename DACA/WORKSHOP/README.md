## 🎯 Purpose

The **WORKSHOP** folder is the **main coding workspace** for the DACA project. This is where I write, test, and run all my Python scripts, SQL queries, and data analysis notebooks.

It contains:
- A **Python virtual environment** (`.venv/`) that isolates project dependencies
- A **requirements file** (`requirements.txt`) listing all installed packages
- The **`__pycache__/`** folder (auto‑generated by Python)
- The **`output/`** folder for storing generated files (charts, exports, etc.)

---

```text
