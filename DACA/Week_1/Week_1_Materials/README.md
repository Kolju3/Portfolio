## 📌 Overview

This folder contains all the **course materials** provided during Week 1 of the DACA programme. The focus of this week is **SQL Basics** – learning how to read, filter, sort, and count data using SQL.

The materials are divided into two main subfolders:
- **`N1_0_1_P_IT_SQL_pohi_v2.9.docx` and related files** – The main workbook and reference materials
- **`Week_1_RAG/`** – RAG-optimised background documents for NotebookLM
