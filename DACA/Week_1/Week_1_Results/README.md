## 📌 Overview

This folder contains the **results, outputs, and deliverables** from Week 1 of the DACA programme. Unlike Week 0 (which focused on environment setup), Week 1 involved **actual SQL work** – exploring the UrbanStyle database, identifying data quality issues, and documenting findings.

The outputs are organised into four subfolders:

| Subfolder | Contents |
| :--- | :--- |
| **Week_1_Conclusions/** | Summary of the week's outcomes and key findings |
| **Week_1_Pictures/** | Screenshots of SQL queries and results |
| **Week_1_Presentation/** | Group presentation materials (PDF) |
| **Week_1_Tables/** | CSV exports of query results |
