## 💡 Key Learnings

### 1. CV is a Marketing Document

- **Before:** I thought CV was a biography – list everything I've done
- **After:** CV is a marketing document – highlight results, not just activities
- **Lesson:** Every bullet point must answer "So what? What was the impact?"

### 2. Numbers Make the Difference

| Generic | Quantified |
| :--- | :--- |
| "Worked with sales data" | "Analyzed 10,000+ sales records using SQL" |
| "Created dashboards" | "Designed interactive dashboards for C-level stakeholders" |
| "Used Python for analysis" | "Built automated RFM pipeline saving 4h/week" |

**Lesson:** If you can't quantify it, it's not compelling.

### 3. The "Aha Moment"

The ideal candidate described in the hiring guide is... us.

| Area | Match |
| :--- | :--- |
| Technical skills | ✅ SQL, Python, Power BI |
| Portfolio | ✅ 8 weeks of UrbanStyle work on GitHub |
| Teamwork | ✅ Weekly group work |
| AI usage | ✅ Used throughout the programme |
| Career changer | ✅ Physics research background + new data skills |

**Lesson:** You don't need to convince yourself you're valuable – the evidence is already there.

### 4. LinkedIn is Your 24/7 Recruiter

- **Before:** LinkedIn was just a place to have a profile
- **After:** LinkedIn is a tool that works for you 24/7
- **Lesson:** Optimize headline, About, Featured, and Open to Work

### 5. Group Work Was Non-Competitive

- **Before:** I worried about comparing my CV to others
- **After:** We focused on employer perspective, not individual comparison
- **Lesson:** This made the session safe and productive
