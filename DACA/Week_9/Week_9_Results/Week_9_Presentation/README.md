## 🔍 My Specific Contribution (Roll B – Technical Interviewer)

**My task:** Create the section describing **what a technical interviewer should look for in a candidate's code and GitHub**.

### What I Included

| Category | Criteria |
| :--- | :--- |
| **Code Quality** | Readability, comments, structure, modularity |
| **Tool Proficiency** | SQL (PostgreSQL), Python (Pandas, Plotly), Git |
| **Documentation** | READMEs, commit messages, clear explanations |
| **AI Usage** | Understanding AI-generated code (not just copying) |

### Green Flags (Strong Candidate)

| Flag | Explanation |
| :--- | :--- |
| ✅ **Modular code** | Code is divided into logical functions/classes |
| ✅ **Dynamic code** | Easily adaptable (config files, parameters) |
| ✅ **GitHub usage** | Regular commits, branches, PRs with meaningful messages |

### Red Flags (Warning Signs)

| Flag | Explanation |
| :--- | :--- |
| ❌ **No comments** | Code lacks explanations of why or how things are done |
| ❌ **AI-generated code without understanding** | Can't explain what the code does or why it's written that way |

### What to Focus On vs. What to Ignore

| Focus On | Ignore |
| :--- | :--- |
| Transferable skills from other fields | Strict years of experience |
| Presentation skills | Specific programming language (can learn) |
| Data understanding | Tool-specific experience |
| AI tool proficiency | Formatting perfection |

## 📊 Team Summary Findings

| Role | Key Finding |
| :--- | :--- |
| **Roll A – Hiring Manager** | CV must be quantified; ATS-friendly; LinkedIn headline must include "Data Analyst" + skills |
| **Roll B – Technical Interviewer** | Code must be modular, documented, and understandable; GitHub activity shows collaboration |
| **Roll C – People Manager** | Soft skills: communication, problem-solving, cultural fit |
| **Roll D – Team Lead** | Independence, collaboration, growth potential |

---

## 💡 Recommendations Made

| Priority | Recommendation |
| :--- | :--- |
| 1 | **Check GitHub first** – code quality tells more than CV claims |
| 2 | **Use STAR-based questions** – structured answers reveal real experience |
| 3 | **Look for AI understanding** – candidates should know what AI-generated code does |
| 4 | **Value transferable skills** – previous career experience is an advantage, not a weakness |

## 🧠 Key Takeaways

### What We Learned

1. **Hiring is a multi-perspective process** – each role (HR, technical, people, team lead) looks for different things
2. **Green flags and red flags are practical** – they make hiring decisions more objective
3. **The "aha moment"** – the ideal candidate we described in the hiring guide is... us! We have the skills, portfolio, and experience.

### What We Accomplished

- ✅ Created a complete Hiring Guide chapter from the employer perspective
- ✅ Identified green and red flags for technical assessment
- ✅ Made practical recommendations for UrbanStyle
- ✅ Learned what employers are actually looking for
