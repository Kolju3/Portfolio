## 🔍 My Specific Contribution (Roll B – Technical Interviewer)

**My task:** Define what a technical interviewer should look for in a candidate's code and GitHub.

### What I Produced

| Category | Criteria |
| :--- | :--- |
| **Code Quality** | Readability, comments, structure, modularity |
| **Tool Proficiency** | SQL (PostgreSQL), Python (Pandas, Plotly), Git |
| **Documentation** | READMEs, commit messages, clear explanations |
| **AI Usage** | Understanding AI-generated code (not just copying) |

### Green Flags (Strong Candidate)

| Flag | Explanation |
| :--- | :--- |
| ✅ **Modular code** | Code is divided into logical functions/classes |
| ✅ **Dynamic code** | Easily adaptable (config files, parameters) |
| ✅ **GitHub usage** | Regular commits, branches, PRs with meaningful messages |

### Red Flags (Warning Signs)

| Flag | Explanation |
| :--- | :--- |
| ❌ **No comments** | Code lacks explanations of why or how things are done |
| ❌ **AI-generated code without understanding** | Can't explain what the code does or why it's written that way |

## 📊 Key Findings Summary

### 1. CV Building

| Finding | Detail |
| :--- | :--- |
| **CV is a marketing document** | Not a biography – focus on results, not just activities |
| **Quantification is essential** | Every bullet point must have numbers (€, %, hours, records) |
| **ATS optimization** | 70% of large companies use machine filtering |
| **Career changer advantage** | Previous experience + new data skills = unique combination |

### 2. Interview Preparation

| Finding | Detail |
| :--- | :--- |
| **STAR method** | Situation, Task, Action, Result – structured answers |
| **Technical questions** | SQL (GROUP BY, JOINs, window functions), Python (pandas) |
| **Portfolio walk-through** | 5-min pitch: Hook → Problem → Approach → Results → Impact |
| **Questions to ask** | Team, role, culture, company |

### 3. LinkedIn Optimization

| Finding | Detail |
| :--- | :--- |
| **Headline formula** | `[Role] | [Key Skills] | [Value Proposition]` |
| **About section** | 3 paragraphs (who, what, offer) |
| **Featured section** | GitHub, dashboard screenshot, DACA post |
| **Open to Work badge** | Active and visible to recruiters |

### 4. Hiring Guide (Group Work)

| Finding | Detail |
| :--- | :--- |
| **Multi-perspective hiring** | Different roles (HR, technical, people, team lead) look for different things |
| **Green flags** | Modular code, dynamic code, GitHub usage, documentation |
| **Red flags** | No comments, AI-generated code without understanding |
