### 9_0_R1_career_hr_concepts-rag.md – Career Fundamentals

This document covers the **core career concepts** needed for Week 9 of the DACA programme.

#### Key Topics Covered

| Topic | Description |
| :--- | :--- |
| **Estonian Job Market** | 56+ active data analyst roles, salary ranges (€1,800-€2,800/month for juniors) |
| **What Employers Look For** | Technical skills, soft skills, domain knowledge, AI proficiency |
| **Different Data Analyst Roles** | Data Analyst, Business Analyst, BI Analyst, Marketing Analyst, Operations Analyst |
| **CV Building** | Structure, quantification, ATS optimization, career changer positioning |
| **LinkedIn Optimization** | Headline formula, About section, Featured section, Open to Work badge |
| **Interview Preparation** | STAR method, technical questions, portfolio walk-through, salary negotiation |
| **Portfolio as Differentiator** | Why GitHub portfolio matters more than CV claims |
| **Career Changer Advantage** | Previous experience + new data skills = unique combination |
| **Common Job Search Mistakes** | Spray-and-pray, not customizing CV, no follow-up, underestimating previous experience |

#### Key Insights from RAG

**CV is a marketing document, not a biography.** Every bullet point must have numbers.

**The "aha moment":** You described the ideal candidate in the hiring guide – and that candidate is you.

**Career changer advantage:** Previous experience + new data skills = unique combination that pure technical candidates don't have.

### 9_0_R2_career_hr_urbanstyle_application-rag.md – UrbanStyle Application

This document covers the **practical application** of career concepts in the UrbanStyle context.

#### Key Topics Covered

| Topic | Description |
| :--- | :--- |
| **Liis Koppel's Challenge** | Hiring 7 new data analysts – 5 in Estonia, 2 remote (Finland, Germany) |
| **Employer Perspectives** | What each UrbanStyle leader (CEO, IT Director, Marketing Lead) looks for |
| **Hiring Guide Creation** | 6 chapters covering the entire hiring process |
| **DACA Skills Translation** | How to present Week 1-8 skills in employer language |
| **Remote Hiring Context** | Finland and Germany-specific considerations |
| **Green and Red Flags** | What makes a candidate strong or weak |

#### Key Insights from RAG

**Each leader looks for different things:**
- **Toomas (IT Director):** Code quality, SQL/Python skills, Git usage
- **Kristi (CEO):** Business thinking, results presentation, growth potential
- **Anna (Marketing Lead):** Visual presentation, marketing knowledge, communication
- **Marko (Product Manager):** Data exploration, product understanding, automation
- **Liis (Operations Manager):** Accuracy, operational thinking, teamwork

**Remote hiring considerations:**
- **Finland:** Low hierarchy, directness, independence
- **Germany:** Structured, thorough, more formal communication

## 📋 Key Takeaways from RAG Files

### 1. Quantification is Everything

| Generic | Quantified |
| :--- | :--- |
| "Worked with sales data" | "Analyzed 10,000+ sales records using SQL" |
| "Created dashboards" | "Designed interactive dashboards for C-level stakeholders" |
| "Used Python for analysis" | "Built automated RFM pipeline saving 4h/week" |

### 2. Different Leaders Look for Different Things

| Leader | What They Look For |
| :--- | :--- |
| **CEO** | Business thinking, results, growth potential |
| **IT Director** | Code quality, SQL/Python, Git |
| **Marketing Lead** | Visual presentation, communication |
| **Product Manager** | Data exploration, automation |
| **Operations Manager** | Accuracy, operational thinking |

### 3. Career Changer Status is an Advantage

Previous experience + new data skills = unique combination. You understand business context that pure technical people don't.

### 4. The Hiring Guide is Also Your Guide

The criteria you create for hiring are the same criteria you should use to assess your own materials.
