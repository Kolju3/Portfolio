## 📌 Overview

This folder contains **screenshots** of the Week 6 dashboard during development. Unlike previous weeks, these images document **style experiments** – different colour schemes, axis formatting, and chart layout variations explored while polishing the dashboard.

All screenshots were taken from the **Plotly + Streamlit dashboard (Track B)** on **Linux Mint**.

---

## 🎯 Purpose of These Screenshots

These images capture the **iterative design process**:

| Screenshot Type | Purpose |
| :--- | :--- |
| **Colour Variations** | Testing different colour palettes for accessibility and aesthetics |
| **Axis Formatting** | Adjusting tick formats, prefixes, and label positions |
| **Layout Experiments** | Different arrangements of KPI cards and charts |
| **Annotation Styles** | Trying different text positions, arrow styles, and backgrounds |

| Experiment | Why It Matters |
| :--- | :--- |
| **Colour Testing** | Ensures accessibility for colour-blind viewers |
| **Axis Formatting** | Makes numbers more readable (€ prefix, thousand separators) |
