## 📌 Overview

This folder contains the **results, outputs, and deliverables** from Week 6 of the DACA programme. Week 6 focused on **data storytelling and dashboard publishing** – transforming the Week 5 prototype into a polished, investor-ready tool.

The outputs are organised into four subfolders:

| Subfolder | Contents |
| :--- | :--- |
| **Week_6_Conclusions/** | Written conclusions and business insights |
| **Week_6_Pictures/** | Dashboard screenshots (style experiments) |
| **Week_6_Presentation/** | Group presentation materials |
| **Week_6_Tables/** | Empty – all data is live from Supabase |
