## 📌 Overview

This folder contains all the **course materials** provided during Week 6 of the DACA programme. The focus of this week is **Data Storytelling & Dashboard Publishing** – learning how to add narrative context to visualisations, annotate charts, write executive summaries, and deploy live dashboards.

The materials are divided into two main subfolders:
- **Main materials** – The workbook, polishing guides, and storytelling fundamentals
- **`Week_6_RAG/`** – RAG-optimised background documents for NotebookLM
