## 📌 Overview

This folder contains all the **course materials** provided during Week 2 of the DACA programme. The focus of this week is **SQL Data Cleaning** – learning how to identify and handle duplicates, NULL values, and inconsistent data formats in the UrbanStyle database.

The materials are divided into two main subfolders:
- **Main materials** – The workbook and group work guide
- **`Week_2_RAG/`** – RAG-optimised background documents for NotebookLM
