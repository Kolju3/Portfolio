## 📌 Overview

This folder contains the **results, outputs, and deliverables** from Week 2 of the DACA programme. Week 2 focused on **data quality auditing and SQL cleaning** – systematically identifying duplicates, NULL values, logical errors, and inconsistencies across UrbanStyle's sales, customer, and product data.

The outputs are organised into four subfolders:

| Subfolder | Contents |
| :--- | :--- |
| **Week_2_Conclusions/** | Summary of the week's outcomes and key recommendations |
| **Week_2_Pictures/** | Screenshots (empty – no screenshots were taken this week) |
| **Week_2_Presentation/** | Group presentation PDF (data quality audit report) |
| **Week_2_Tables/** | CSV exports of query results |
