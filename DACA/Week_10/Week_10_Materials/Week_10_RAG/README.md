## 📚 File Details

### 10_0_R1_portfolio_defense_concepts-rag.md – General Portfolio Defense

This document covers the **general principles** of presenting data analytics work to stakeholders.

#### Key Topics

| Topic | Description |
| :--- | :--- |
| **Why Portfolio Matters** | How a good portfolio differentiates you in the job market |
| **GitHub Profile Optimisation** | Professional READMEs, pinned repositories, and profile settings |
| **Project README Structure** | Business problem → Approach → Findings → Technical details |
| **AI Usage Documentation** | How to responsibly document AI use in your projects |
| **7‑Minute Pitch Structure** | Hook → Problem → Approach → Results → Impact |
| **STAR Method** | Situation, Task, Action, Result – for answering questions |
| **Shu‑Ha‑Ri Reflection** | How to tell your learning story using this framework |
| **Data Storytelling** | Using Knaflic’s principles to communicate insights effectively |

### 10_0_R2_portfolio_defense_urbanstyle_application-rag.md – UrbanStyle Application

This document applies the general concepts specifically to the UrbanStyle context.

#### Key Topics

| Topic | Description |
| :--- | :--- |
| **Board Meeting Context** | UrbanStyle’s investors and board expect data‑driven decision‑making |
| **Team Presentation Structure** | 7‑minute format: Intro → Relay → Synthesis → Recommendations → AI Usage |
| **Relay Format** | Each team member presents their strongest project (45 seconds) |
| **Synthesis** | “What UrbanStyle learned from our work” – answering the “So what?” question |
| **Common Board Questions** | Preparation for likely questions (methodology, trust, scaling, business impact) |
| **Shu‑Ha‑Ri Examples** | How to frame your personal growth story for the board |
| **AI Integration** | Demonstrating responsible and effective AI use |
